# 鉄道路線マップ

国土数値情報の鉄道・駅GeoJSONを、MapLibre GL JSとOpenFreeMapのOpenStreetMapベクター地図に重ねて表示するWeb地図です。背景スタイルから国境・海上境界レイヤーを除外しています。

## 主な機能

- 事業者・路線の階層表示と絞り込み
- 事業者選択時の自動ズームをオン・オフ可能（設定はブラウザに保存）
- 事業者・路線・駅の横断検索
- 選択路線への自動ズーム
- 路線は最初の選択で色を変更し、同じ路線をもう一度選択すると全体が収まるよう自動ズーム
- 地図上で選んだ路線をサイドバーでも自動選択し、その位置までスクロール
- `railway-order.json` に記載した事業者・路線の順番で一覧表示
- ドラッグ移動、ホイールおよびボタンによる拡大縮小
- 地図上では待機中・マウスオーバー中・ドラッグ中とも普通の矢印カーソルを維持
- 路線・駅のツールチップ
- 選択状態をURLへ保存
- PC・スマートフォン対応のレスポンシブUI
- 地図の移動範囲を日本周辺へ制限
- サイドバーからバージョン情報を表示

## 起動方法

GeoJSONを`fetch()`で読み込むため、ローカルHTTPサーバーから開いてください。

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## ファイル

- `index.html`: 画面構造とスタイル
- `railwayMap.js`: UI、検索、選択、地図操作
- `railwayMapTools.js`: 旧D3.js版の補助処理（現行画面では未使用）
- `N02-21_RailroadSection.geojson`: 路線データ
- `N02-21_Station.geojson`: 駅データ
- `railway-order.json`: 事業者と路線の表示順。配列を並べ替えると画面にも反映されます

路線データについて

使用している路線データは以下のサイトの2021年版を使用しています。
国土交通省国土数値情報ダウンロードサイト
このデータは「鉄道要覧」等を参照して作成されています。事業者名、路線名、路線の範囲等は一般に使用されているものとは異なる場合があります。例えば「JR東日本」は「東日本旅客鉄道」、例えば「山手線」は環状ではなく「品川～新宿～田端」です、例えば「常磐線」は「上野～仙台」ではなく「日暮里～岩沼」です。
